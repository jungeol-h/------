# 나매크 UX 개선 계획 — "적은 수정으로 큰 효과"

## Context

최근 급격한 기능 추가·역할 확장(7개 role, 6개 대시보드)으로 UX 구조 개선이 필요한 시점.
코드 리팩토링보다 **사용자 체감 UX 개선**이 목표이며, "적은 수정으로 큰 효과"가 제약 조건.

베타 실사용자: 학생(중학생, 매일) · 학습매니저(매일) · 관리자(매일) · 강사/상담사(주기적) · 학부모/열람자(가끔).

**결정: 이번 세션은 계획 문서 확정까지만. 구현은 별도 진행.**
(사용자 선택: Tier 1 → 베타 반응 확인 → Tier 2 순서 권장)

### 탐색으로 검증된 핵심 문제

1. **admin 하단탭 6개** — 6칸이라 터치 타깃 좁음, 외부상담은 주기적 업무인데 상시 탭
2. **StudentDetailPage 상단 탭 7개 가로 스크롤** — 매일 쓰는 '상담' 탭이 7번째라 스크롤해야 보임 (`src/platform/pages/shared/StudentDetailPage.jsx:821`)
3. **알림 벨 배지 불일치** — Header 벨 배지는 manager만 연결, admin은 홈 카드로만, 클릭 불가 장식
4. **로딩 스피너 13벌 복붙, 빈 상태 텍스트 38곳 산발** — 공용 컴포넌트 없음, 톤 불일치
5. **admin 홈 순서 문제** — 정적 인원 테이블이 최상단, 오늘 할 일(긴급보고·업무일정)이 스크롤 아래
6. **학생 홈** — 선생님 한마디가 맨 아래, 오전엔 항상 빈 차트가 화면 차지
7. **임시 타이머 공지 모달** — 철수 시점 지난 죽은 UI
8. **manager 학생 리스트에 검색 없음** — educator 리스트에는 있어 역할 간 불일치

**건드리지 않는 것 (모범 패턴)**: `CounselingTabContent` 4역할 props 재사용, PageLayout/Header/TabBar 셸 공유.

## Tier 1 — 하루 분량, 즉시 체감 (8건)

### T1-1. admin 하단탭 6→5개 (외부상담을 홈 카드로 이동)
- **파일**: `src/platform/pages/admin/AdminDashboard.jsx:20` (TABS에서 external 제거, 라우트는 유지), `src/platform/pages/admin/AdminHomeTab.jsx:256-279` ("상세 메뉴"에 외부상담 NavCard 추가)
- consultant 쪽 탭(EducatorDashboard)은 무변경. 작업량 30분.

### T1-2. StudentDetailPage 7탭: 스크롤 칩 → 4열 그리드 2줄 + 빈도순 재배열
- **파일**: `src/platform/pages/shared/StudentDetailPage.jsx:776` (TABS), `:821-835` (렌더), `:837-843` (인덱스 분기)
- Before: `flex overflow-x-auto` 스크롤, 순서 [마인드·일기·학습·과제·학습진단·진로설계·상담]
- After: `grid grid-cols-4 gap-1` 2줄 전체 노출. 순서 재배열 — **1줄: 마인드·학습·과제·상담**(매일), **2줄: 일기·학습진단·진로설계**(주기적)
- 인덱스 기반 `activeTab === 0 && ...` 분기를 **key 기반**(`'mind'`, `'counseling'`, …)으로 전환 — T2-2(URL 동기화)의 기반. 작업량 1시간.

### T1-3. admin 헤더 벨 배지 연결 (미확인 긴급 업무보고 수)
- **파일**: `src/platform/pages/admin/AdminDashboard.jsx:56` — `badge={unconfirmedUrgent}` 전달 (AdminHomeTab의 unconfirmedUrgent 계산 로직 재사용, ManagerDashboard 패턴 복제)
- **배지 통일 규칙** (코드 주석으로 문서화): *벨 배지 = "지금 처리해야 할 항목 수", 역할당 단일 소스 1개*
  - manager: 담당 학생 마인드 위험 수 (현행)
  - admin: 미확인 긴급 업무보고 수 (신규)
  - student/educator/viewer/parent: 배지 없음 (학생은 홈 말풍선으로 충분, 나머지는 노이즈 방지)
- 작업량 30분.

### T1-4. `PageLoader` + `EmptyState` 공통 컴포넌트 신설
- **신규**: `src/platform/components/common/PageLoader.jsx`, `src/platform/components/common/EmptyState.jsx`
- **교체**: 6개 대시보드의 동일한 12줄 로딩 블록 (예: `AdminDashboard.jsx:34-43`)
- `EmptyState({ icon, title, description, action })` — py-12 중앙정렬, 아이콘 원형 배경
- **UX 카피 가이드** (JSDoc에 포함):
  - 학생: 해요체 + 다음 행동 제안 — "아직 오늘 학습 기록이 없어요"
  - 운영진: 합니다체 + 원인·해결 — "조건에 맞는 학생이 없습니다 · 필터를 확인해 주세요"
- 작업량 2시간. 나머지 38곳은 T2-5에서 점진 적용.

### T1-5. admin 홈 섹션 재배열 + 중복 NavCard 삭제
- **파일**: `src/platform/pages/admin/AdminHomeTab.jsx:79-286` (JSX 블록 이동만, 로직 무변경)
- Before: ①인원현황 ②핵심지표 ③마인드위험 ④정합성 ⑤오늘업무 ⑥상세메뉴 ⑦통계
- After: ①**핵심지표**(긴급보고 최상단) ②**오늘의 업무 일정** ③마인드위험 ④정합성 ⑤인원현황 ⑥상세메뉴(사용자관리·확인평가 카드는 하단탭과 중복이라 삭제, T1-1 외부상담 카드로 대체) ⑦통계
- 작업량 30분.

### T1-6. 학생 홈 재배열: 선생님 한마디 위로, 빈 차트 숨김
- **파일**: `src/platform/pages/student/DashboardTab.jsx:50-172`
- After 순서: ①배너 ②**알림·선생님 한마디**(있을 때만, 149행 블록을 위로) ③시계 타임테이블 ④요약카드3 ⑤과제현황 ⑥과목별 차트 — `subjectData.length > 0`일 때만 섹션 렌더 (95행 빈 박스 분기 제거)

### T1-7. 임시 타이머 공지 모달 철거
- **파일**: `src/platform/pages/student/StudentDashboard.jsx` (TimerFixNoticeModal 관련 제거), `src/platform/pages/student/tempBetaNotice.js` 삭제

### T1-8. manager 학생 리스트에 검색 추가
- **파일**: `src/platform/pages/manager/StudentListTab.jsx` — `EducatorStudentListTab.jsx:46-55`의 검색 input + query filter 이식 (카드 마크업은 이미 동일)

## Tier 2 — 2~3일, 구조 개선 (5건)

### T2-1. 헤더 벨 클릭 가능화 + 이동 규칙
- `Header.jsx:51-58`의 `<div>` → `<button>`, `badgeTo` prop 추가 (manager→`/manager/home`, admin→`/admin/home`). 배지 0이면 벨 숨김 유지.

### T2-2. StudentDetailPage 탭 URL 동기화 + sticky
- `useState` → `useSearchParams()`로 `?tab=counseling` 동기화 (T1-2의 key 기반 전환이 전제)
- 부수효과: 홈의 마인드 위험 카드 → `?tab=mind` 직행 링크 가능
- 7탭 그리드 `sticky top-14 z-30` 고정 — 뒤로가기/새로고침 시 탭 유지, 스크롤 중 위치 상실 해소

### T2-3. `StudentSummaryCard` 공유 컴포넌트
- manager/educator 리스트 카드 복붙 쌍둥이(~70줄×2)를 `src/platform/components/student/StudentSummaryCard.jsx`로 통합. CounselingTabContent 패턴 준수.
- admin UserManagementTab(관리 테이블)·ExternalStudentList(별도 도메인)는 용도가 달라 **통합 제외**.

### T2-4. `ModalShell` — 일일 사용 빈도 상위 3곳만
- 신규 `src/platform/components/common/ModalShell.jsx` (backdrop + ESC + 바깥클릭 + body scroll lock + `role="dialog"`)
- 적용: ManagerHomeTab 코칭 모달, CounselingFormModal, StudentFormModal. 나머지 19곳은 Tier 3.

### T2-5. EmptyState 카피 확산
- 매일 노출되는 빈 상태 ~12곳(학생 과제/마인드/진단, 매니저 출결/업무보고, admin 업무일정 등) 교체.

## 시행 순서 (구현 시)

Tier 1을 2회로 분할 배포 권장:
1. **1차 (무위험)**: T1-4 공통 컴포넌트 + T1-7 죽은 모달 철거 + T1-3 배지 연결
2. **2차 (배치 변경)**: T1-1/2/5/6/8 — 습관을 깨는 변경이므로 몰아서 한 번에 + 매니저에게 "홈 배치 변경" 공지 한 줄

## 검증 방법 (구현 시)

- `npm run dev` 후 각 역할 계정으로 로그인 확인: admin 탭 5개·외부상담 홈 카드 진입, 학생상세 7탭 2줄 노출·상담 탭 즉시 보임, admin 벨 배지(긴급보고 생성→배지 증가), 학생 홈 오전(빈 차트 숨김)·기록 후(차트 표시)
- `npm run lint`, `npm run test` 통과
- 배치 변경은 375px(iPhone SE) 뷰포트 기준 확인
